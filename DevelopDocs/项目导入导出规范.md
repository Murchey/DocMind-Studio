# 项目导入导出规范

> 定义 DocMind-Studio 工作区项目的导出（`.dms`）和导入标准，包含文件格式、manifest 结构、Extension 对接说明。

涉及模块：
- `Extension/src/utils/projectExporter.ts` — 核心打包/解包逻辑
- `Extension/src/extension.ts` — 命令注册
- `Extension/src/webview/dashboardPanel.ts` — Dashboard UI 按钮

---

## 1. `.dms` 文件格式

### 1.1 定义

`.dms`（**D**oc**M**ind **S**tudio Project）是 DocMind-Studio 的项目归档文件格式。

- **本质**：ZIP 压缩包，扩展名改为 `.dms`
- **MIME 类型**：`application/x-docmind-project`
- **用途**：完整保存一个工作区项目的所有 Agent 数据、知识库和产出物，支持跨机器迁移和直接恢复

### 1.2 内部结构

```
项目名.dms (ZIP)
├── project_manifest.json          # 项目元数据（必需）
├── doc-content-analysis/          # Agent 工作目录
│   ├── input/                     # 原始输入
│   ├── converted/                 # 转换中间产物
│   └── summary/                   # 提取结果 + manifest
├── doc-form-master/
│   ├── input/
│   ├── output/                    # 格式化输出
│   └── validated/
├── excel-master/
├── ppt-master/
├── knowledge-base/                # 知识库（可选）
│   ├── kb-manifest.json
│   └── ...
└── ...其他 Agent 目录
```

### 1.3 排除规则

导出时自动排除以下文件：

| 文件 | 原因 |
|------|------|
| `.workflow_state.json` | 工作流运行时状态，不应跨会话传递 |
| `.docmind-progress.json` | 进度文件，临时数据 |
| `.kb_state.json` | 知识库增量状态，导入后需重新生成 |
| 以 `.` 开头的文件 | 隐藏文件/临时文件 |
| `*.tmp` | 临时文件 |

## 2. project_manifest.json 结构

`.dms` 文件根目录下的 `project_manifest.json` 是项目元数据的核心，用于导入时恢复项目上下文。

### 2.1 字段定义

```json
{
  "format_version": "1.0",
  "exported_at": "2026-07-21T17:30:00Z",
  "source": "DocMind-Studio",
  "project_name": "ChlorphenaminePaper",
  "scope": "full",
  "agents": [
    {
      "name": "doc-content-analysis",
      "folders": ["input", "converted", "summary"],
      "artifact_count": 12
    },
    {
      "name": "doc-form-master",
      "folders": ["input", "output", "validated"],
      "artifact_count": 3
    }
  ],
  "knowledge_base": {
    "doc_count": 5,
    "keyword_count": 120
  },
  "total_files": 45,
  "total_size_bytes": 2048576,
  "description": ""
}
```

### 2.2 字段说明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `format_version` | string | 是 | 格式版本号，当前为 `"1.0"` |
| `exported_at` | string | 是 | 导出时间（ISO 8601） |
| `source` | string | 是 | 固定为 `"DocMind-Studio"` |
| `project_name` | string | 是 | 项目名称，导入时用作 WORKSPACE 子目录名 |
| `scope` | string | 是 | 导出范围：`"full"` / `"output-only"` / `"custom"` |
| `agents` | array | 是 | 包含的 Agent 列表 |
| `agents[].name` | string | 是 | Agent 目录名 |
| `agents[].folders` | string[] | 是 | 包含的子目录列表 |
| `agents[].artifact_count` | int | 是 | 该 Agent 下的产出文件数 |
| `knowledge_base` | object | 否 | 知识库概要信息 |
| `knowledge_base.doc_count` | int | 否 | 知识库文档数 |
| `knowledge_base.keyword_count` | int | 否 | 关键词数 |
| `total_files` | int | 是 | 总文件数 |
| `total_size_bytes` | int | 是 | 总字节数 |
| `description` | string | 否 | 项目描述（预留字段） |

## 3. 导出流程

### 3.1 触发方式

| 入口 | 位置 | 说明 |
|------|------|------|
| Dashboard Projects 视图 | 每个项目卡片的 `Export` 按钮 | `data-action="exportProject"` |
| TreeView Results | 项目节点右键 → `DocMind: Export Project` | `docmindExportable` context |
| 命令面板 | `DocMind: Export Project` | `docmind.exportProject` |

### 3.2 导出参数选择

```
选择导出范围:
  ○ Full Package        — 所有 Agent 数据
  ○ Output Only         — 仅 output/summary/validated
  ○ Custom Selection    — 用户选择特定 Agent

选择导出格式:
  ● DocMind Project (.dms)  — 带元数据，可直接恢复
  ○ Copy to Directory       — 复制到目标文件夹
```

### 3.3 导出范围说明

| scope | 打包内容 | 典型场景 |
|-------|---------|---------|
| `full` | 整个 `WORKSPACE/{ProjectName}/` | 完整迁移、备份 |
| `output-only` | 每个 Agent 的 `output/`、`summary/`、`validated/` | 仅分享最终成果 |
| `custom` | 用户选择的 Agent 子目录 | 部分分享 |

### 3.4 核心 API

```typescript
// 导出入口
exportProject(options: ExportOptions): Promise<ExportResult>

// 选项
interface ExportOptions {
  projectName: string;     // 项目名
  projectPath: string;     // 项目绝对路径
  scope: 'full' | 'output-only' | 'custom';
  format: 'dms' | 'copy';
  includeAgents?: string[]; // custom 模式下的 Agent 列表
}
```

## 4. 导入流程

### 4.1 触发方式

| 入口 | 说明 |
|------|------|
| 双击 `.dms` 文件 | VS Code 文件关联 → `docmind.openDmsFile` 命令 |
| Dashboard `Import` 按钮 | Header 栏按钮 → `docmind.importProject` |
| 命令面板 `DocMind: Import Project` | QuickPick 选来源（.dms / .zip / 文件夹） |
| 命令面板 `DocMind: Open Project File` | 直接选择 `.dms` 文件 |

### 4.2 导入流程图

```
用户选择 .dms 文件
    ↓
读取 project_manifest.json
    ↓
提取 project_name（优先 manifest，否则取文件名）
    ↓
检查 WORKSPACE/{project_name} 是否存在
    ↓
  ┌─ 不存在 → 直接创建
  └─ 存在 → 弹出冲突处理:
        ● Overwrite  — 删除旧项目，重新导入
        ● Rename     — 输入新项目名
        ● Cancel     — 取消导入
    ↓
解压 .dms 到临时目录
    ↓
检测 ZIP 内层结构（可能有一层项目名子目录）
    ↓
复制到 WORKSPACE/{project_name}/
    ↓
清理临时目录
    ↓
刷新 Dashboard + 提示 "Open Project"
```

### 4.3 `.dms` 文件关联

VS Code 通过 `package.json` 的 `languages` 配置识别 `.dms` 文件：

```json
{
  "languages": [{
    "id": "docmind-dms",
    "aliases": ["DocMind Project", "dms"],
    "extensions": [".dms"],
    "mimetypes": ["application/x-docmind-project"]
  }]
}
```

双击 `.dms` 文件时，VS Code 激活扩展并触发 `docmind.openDmsFile` 命令。

### 4.4 核心 API

```typescript
// 从 .dms 文件导入（直接路径）
importFromDms(workspaceRoot: string, dmsFilePath: string): Promise<ImportResult>

// 从文件选择器导入（弹出对话框，支持 .dms 和 .zip）
importFromZip(workspaceRoot: string): Promise<ImportResult>

// 从文件夹导入
importFromFolder(workspaceRoot: string): Promise<ImportResult>

// 结果
interface ImportResult {
  success: boolean;
  projectPath: string;    // 导入后的项目路径
  projectName: string;    // 项目名
  fileCount: number;      // 导入文件数
  error?: string;         // 错误信息
}
```

## 5. Extension 命令注册

### 5.1 命令清单

| 命令 | 说明 | 触发方式 |
|------|------|---------|
| `docmind.exportProject` | 导出项目 | 右键菜单 / Dashboard 按钮 |
| `docmind.importProject` | 导入项目 | Dashboard 按钮 / 命令面板 |
| `docmind.openDmsFile` | 打开 .dms 文件 | 双击文件 / 命令面板 |

### 5.2 package.json 配置

```json
{
  "commands": [
    { "command": "docmind.exportProject", "title": "DocMind: Export Project", "icon": "$(package)" },
    { "command": "docmind.importProject", "title": "DocMind: Import Project", "icon": "$(cloud-download)" },
    { "command": "docmind.openDmsFile", "title": "DocMind: Open Project File", "icon": "$(file-binary)" }
  ],
  "activationEvents": ["onLanguage:docmind-dms"],
  "menus": {
    "view/item/context": [
      {
        "command": "docmind.exportProject",
        "when": "viewItem =~ /docmindExportable/",
        "group": "inline"
      }
    ]
  }
}
```

### 5.3 Dashboard UI 集成

| 位置 | 按钮 | data-action |
|------|------|-------------|
| Projects 视图 · 项目卡片 footer | `Export` | `exportProject` |
| Header 栏 · 右侧按钮组 | `Import` | `importProject` |

Webview 通过 `postMessage` 与 Extension 通信：

```typescript
// Webview → Extension
vscode.postMessage({ type: 'exportProject', name, path });
vscode.postMessage({ type: 'importProject' });

// Extension handleMessage
if (message.type === 'exportProject') { ... }
if (message.type === 'importProject') { ... }
```

## 7. 快速检查清单

### 导出

- [ ] 导出的 `.dms` 内部包含 `project_manifest.json`
- [ ] manifest 包含 `format_version`、`project_name`、`agents` 列表
- [ ] 导出范围（full/output-only/custom）正确过滤目录
- [ ] 排除 `.workflow_state.json`、`.tmp` 等临时文件
- [ ] `.dms` 文件可在文件管理器中被识别

### 导入

- [ ] 双击 `.dms` 文件可自动恢复项目到 WORKSPACE
- [ ] 导入后 Dashboard 自动刷新
- [ ] 同名冲突时弹出 Overwrite/Rename/Cancel 选择
- [ ] 从 `.dms` 中正确提取内层目录结构（处理一层子目录嵌套）
- [ ] 导入完成后显示文件数和 "Open Project" 按钮

### 兼容性

- [ ] 支持 `.dms` 和 `.zip` 两种格式导入
- [ ] 无 `project_manifest.json` 的旧格式可降级为文件名推断
- [ ] Copy 模式导出仍可正常工作
