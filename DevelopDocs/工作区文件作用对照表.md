## 3. WORKSPACE/ 目录

总工作区，按项目和 Agent 隔离，存放所有工作数据。

### 3.1 通用结构

```
WORKSPACE/
├── .docmind-progress.json    # 进度追踪文件（自动生成）
└── {ProjectName}/            # 项目工作区（PascalCase 命名）
    ├── doc-content-analysis/
    ├── doc-form-master/
    ├── excel-master/
    ├── ppt-deep-summary/
    └── phd-research-agent/
```

### 3.2 doc-content-analysis 工作区

```
WORKSPACE/{ProjectName}/doc-content-analysis/
├── input/                        # 输入（只读）
│   ├── report1.doc               # 原始文档
│   ├── report2.docx
│   └── paper.pdf
├── converted/                    # 中间产物
│   ├── report1.docx              # 格式转换后的文件
│   ├── report2.docx
│   └── paper.docx
└── summary/                      # 最终输出
    ├── manifest.json             # 处理清单（调度器入口）
    ├── report1/
    │   ├── text/
    │   │   ├── content.json      # 结构化文档内容
    │   │   ├── summary.json      # 结构化总结索引
    │   │   └── summary.md        # 可读总结
    │   └── img/
    │       ├── image_1.png       # 提取的图片
    │       ├── text/             # OCR 识别结果
    │       │   └── image_1.txt
    │       └── img-summary/      # AI 视觉总结
    │           └── image_1.md
    ├── report2/
    │   └── text/
    │       ├── content.json
    │       ├── summary.json
    │       └── summary.md
    ├── 综合总结.json              # 多文档综合总结
    └── 综合总结.md
```

### 3.3 phd-research-agent 工作区

```
WORKSPACE/{ProjectName}/phd-research-agent/
├── input/                        # 输入（只读）
│   ├── idea.md                   # 研究想法（用于 Idea 评估）
│   ├── research_info.md          # 研究信息（用于 Introduction 起草）
│   └── draft.md                  # 论文草稿（用于论文审阅）
└── summary/                      # 最终输出
    ├── manifest.json             # 处理清单（调度器入口）
    ├── idea_result.json          # Idea 评估结果（结构化）
    ├── idea_result.md            # Idea 评估报告（可读）
    ├── intro_outline.json        # Introduction 大纲（结构化）
    ├── intro_outline.md          # Introduction 大纲（可读）
    ├── review_result.json        # 论文审阅结果（结构化）
    └── review_result.md          # 论文审阅报告（可读）
```

### 3.4 doc-form-master 工作区

```
WORKSPACE/{ProjectName}/doc-form-master/
├── input/                        # 输入（只读）
├── output/                       # 转换输出
├── parsed/                       # 解析结果
└── validated/                    # 验证结果
```

### 3.5 excel-master 排课/日程工作区

```
WORKSPACE/{ProjectName}/excel-master/
├── input/                        # 输入（只读）
│   └── *.md                      # 排课需求文档或知识库分析结果
├── parsed/                       # 中间产物（约束解析结果）
│   └── constraints.json          # 结构化约束数据
├── solution/                     # 中间产物（求解结果）
│   └── schedule.json             # 排课结果
└── output/                       # 最终输出
    ├── schedule_by_class.xlsx    # 按班级分表的课表
    ├── schedule_by_teacher.xlsx  # 按教师分表的课表
    ├── schedule_by_room.xlsx     # 按教室分表的课表
    └── schedule_summary.md       # 摘要报告
```

### 3.6 需求文档传递流程

```
doc-content-analysis 输出:
WORKSPACE/{ProjectName}/doc-content-analysis/summary/
├── manifest.json                 # 处理清单（含 document_type 字段）
└── <文件名>/text/
    ├── summary.json              # 含 document_type: "requirement"
    └── summary.md                # 需求格式的总结

调度器读取 manifest.json:
1. 检查 document_type 字段
2. 对于 requirement 类型，读取 target_agent 字段
3. 将 summary.md 复制到目标 Agent 的 input/ 目录
4. 调用目标 Agent 执行任务

目标 Agent 输入:
WORKSPACE/{ProjectName}/excel-master/input/
└── 需求.md                       # 从 doc-content-analysis 复制的需求文档

## 6. 文件类型说明

| 文件类型 | 说明 | 读写权限 |
|----------|------|----------|
| `*.md` | Markdown 文档，Agent/Skill/Workflow 定义 | 只读（ComponentAgents）、读写（DevelopDocs） |
| `*.json` | 结构化数据文件 | 读写 |
| `*.py` | Python 脚本 | 只读（ComponentAgents） |
| `*.txt` | 纯文本/依赖列表 | 只读 |
| `*.doc/*.docx/*.pdf` | 用户文档 | 只读（input 目录） |
| `*.png/*.jpg` | 图片文件 | 只读（input）、读写（output） |
