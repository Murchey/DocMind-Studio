# 工作区文件作用对照表

本文档列出 DocMind-Studio 项目中所有文件的作用和说明。

---

## 1. 根目录文件

| 文件 | 作用 |
|------|------|
| `AGENTS.md` | 调度器主文件，定义所有 Agent 的调度规则、工作区规范和工作流 |

---

## 2. ComponentAgents/ 目录

Agent 代码目录，存放 Agent 定义和 Skill 实现，**只读，不存放工作数据**。

### 2.1 doc-content-analysis（文档内容分析）

| 文件 | 作用 |
|------|------|
| `AGENT.md` | Agent 定义：文档内容读取与分析，支持 DOC/DOCX/PDF 批量转换、内容提取、图片提取和智能总结 |
| `README.md` | 英文说明文档 |
| `README_CN.md` | 中文说明文档 |
| `requirements.txt` | Python 依赖列表 |

#### SKILLS/doc-convertor（文档转换器）

| 文件 | 作用 |
|------|------|
| `SKILL.MD` | Skill 定义：DOC/DOCX/PDF 文档转换、内容提取与图片提取 |
| `scripts/__init__.py` | Python 包初始化文件 |
| `scripts/doc_converter.py` | 核心脚本：格式转换、文本提取、图片提取 |

#### SKILLS/img-reader（图片读取器）

| 文件 | 作用 |
|------|------|
| `SKILL.MD` | Skill 定义：图片 OCR 文字识别和 AI 视觉分析 |
| `scripts/__init__.py` | Python 包初始化文件 |
| `scripts/img_reader.py` | 核心脚本：OCR 文字识别 |

### 2.2 phd-research-agent（科研辅助）

| 文件 | 作用 |
|------|------|
| `AGENT.md` | Agent 定义：科研辅助，提供 Idea 评估、Introduction 草稿、论文审阅 |
| `README.md` | 说明文档 |

#### SKILLS/idea-evaluator（想法评估器）

| 文件 | 作用 |
|------|------|
| `SKILL.MD` | Skill 定义：评估研究想法的可行性、创新性和价值，五维评分 |

#### SKILLS/intro-drafter（引言起草器）

| 文件 | 作用 |
|------|------|
| `SKILL.MD` | Skill 定义：根据研究信息生成六段式 Introduction 大纲 |

#### SKILLS/pre-submission-reviewer（投稿前审阅器）

| 文件 | 作用 |
|------|------|
| `SKILL.MD` | Skill 定义：论文提交前审阅，检查逻辑、语法、格式问题 |

### 2.3 doc-form-master-main（文档格式处理）

### 2.4 excel-master-main（Excel 处理）

| 文件 | 作用 |
|------|------|
| `AGENT.md` | Agent 定义：Excel 文件处理 |

### 2.5 ppt-deep-summary-main（PPT 深度总结）

| 文件 | 作用 |
|------|------|
| `AGENT.md` | Agent 定义：PPT 深度总结 |

## 3. WORKSPACE/ 目录

总工作区，按项目和 Agent 隔离，存放所有工作数据。

### 3.1 通用结构

```
WORKSPACE/
├── .docmind-progress.json    # 进度追踪文件（自动生成）
└── {ProjectName}/            # 项目工作区（PascalCase 命名）
    ├── doc-content-analysis/
    ├── doc-form-master/
    ├── excel-master/
    ├── ppt-deep-summary/
    └── phd-research-agent/
```

### 3.2 doc-content-analysis 工作区

```
WORKSPACE/{ProjectName}/doc-content-analysis/
├── input/                        # 输入（只读）
│   ├── report1.doc               # 原始文档
│   ├── report2.docx
│   └── paper.pdf
├── converted/                    # 中间产物
│   ├── report1.docx              # 格式转换后的文件
│   ├── report2.docx
│   └── paper.docx
└── summary/                      # 最终输出
    ├── manifest.json             # 处理清单（调度器入口）
    ├── report1/
    │   ├── text/
    │   │   ├── content.json      # 结构化文档内容
    │   │   ├── summary.json      # 结构化总结索引
    │   │   └── summary.md        # 可读总结
    │   └── img/
    │       ├── image_1.png       # 提取的图片
    │       ├── text/             # OCR 识别结果
    │       │   └── image_1.txt
    │       └── img-summary/      # AI 视觉总结
    │           └── image_1.md
    ├── report2/
    │   └── text/
    │       ├── content.json
    │       ├── summary.json
    │       └── summary.md
    ├── 综合总结.json              # 多文档综合总结
    └── 综合总结.md
```

### 3.3 phd-research-agent 工作区

```
WORKSPACE/{ProjectName}/phd-research-agent/
├── input/                        # 输入（只读）
│   ├── idea.md                   # 研究想法（用于 Idea 评估）
│   ├── research_info.md          # 研究信息（用于 Introduction 起草）
│   └── draft.md                  # 论文草稿（用于论文审阅）
└── summary/                      # 最终输出
    ├── manifest.json             # 处理清单（调度器入口）
    ├── idea_result.json          # Idea 评估结果（结构化）
    ├── idea_result.md            # Idea 评估报告（可读）
    ├── intro_outline.json        # Introduction 大纲（结构化）
    ├── intro_outline.md          # Introduction 大纲（可读）
    ├── review_result.json        # 论文审阅结果（结构化）
    └── review_result.md          # 论文审阅报告（可读）
```

### 3.4 doc-form-master 工作区

```
WORKSPACE/{ProjectName}/doc-form-master/
├── input/                        # 输入（只读）
├── output/                       # 转换输出
├── parsed/                       # 解析结果
└── validated/                    # 验证结果
```

---

## 6. 文件类型说明

| 文件类型 | 说明 | 读写权限 |
|----------|------|----------|
| `*.md` | Markdown 文档，Agent/Skill/Workflow 定义 | 只读（ComponentAgents）、读写（DevelopDocs） |
| `*.json` | 结构化数据文件 | 读写 |
| `*.py` | Python 脚本 | 只读（ComponentAgents） |
| `*.txt` | 纯文本/依赖列表 | 只读 |
| `*.doc/*.docx/*.pdf` | 用户文档 | 只读（input 目录） |
| `*.png/*.jpg` | 图片文件 | 只读（input）、读写（output） |
