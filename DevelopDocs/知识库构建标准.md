# 知识库构建标准

涉及 skill/agent/workflow 为：
- knowledge-builder (workflow)
- doc-content-analysis (agent)
- phd-research-agent (agent)
- excel-master (agent)

---

## 输入

### doc-content-analysis 输入

输入内容是文本文档和其他格式的文档。支持两种文档类型：

| 文档类型 | 说明 | 输出目标 |
|----------|------|----------|
| **知识文档** | 技术文档、研究报告、论文等 | knowledge-builder |
| **需求文档** | 排课要求、表格分析需求等 | excel-master |

| 格式 | 说明 |
|------|------|
| `.docx` | Word 文档（直接处理） |
| `.doc` | 旧版 Word 文档（需转换） |
| `.pdf` | PDF 文档（需转换） |
| `.txt` | 纯文本 |
| `.pptx` | PowerPoint 演示文稿 |
| `.ppt` | 旧版 PowerPoint |
| `.xlsx` | Excel 表格 |
| `.xls` | 旧版 Excel |
| `.md` | Markdown 文档 |

### phd-research-agent 输入

输入内容是 Markdown 或纯文本格式的研究相关内容。

| 任务类型 | 输入文件 | 说明 |
|----------|----------|------|
| Idea 评估 | `idea.md` | 研究想法描述 |
| Introduction 起草 | `research_info.md` | 研究信息（领域、局限性、挑战等） |
| 论文审阅 | `draft.md` | 论文草稿 |

### 输入路径

doc-content-analysis:
```
WORKSPACE/{ProjectName}/doc-content-analysis/input/
├── *.doc
├── *.docx
├── *.pdf
└── *.txt
```

phd-research-agent:
```
WORKSPACE/{ProjectName}/phd-research-agent/input/
└── <task_type>.md
```

## 输出

### 输出路径

```
WORKSPACE/{ProjectName}/doc-content-analysis/summary/
├── manifest.json              # 处理清单（调度器入口）
├── <文件名1>/
│   ├── text/
│   │   ├── content.json       # 结构化文档内容
│   │   ├── summary.json       # 结构化总结索引
│   │   └── summary.md         # 可读总结
│   └── img/
│       ├── image_1.png
│       ├── text/              # OCR 结果
│       └── img-summary/       # AI 视觉总结
└── 综合总结.json/md           # 多文档综合总结
```

## 核心字段定义

### 单文档总结 (summary.json)

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 文档唯一标识，如 `doc_001` |
| `title` | string | 是 | 文档标题 |
| `source_file` | string | 是 | 原始文件名 |
| `document_type` | string | 是 | 文档类型：`knowledge`（知识文档）/ `requirement`（需求文档） |
| `author` | string | 否 | 作者 |
| `created_at` | string | 否 | 文档创建时间 |
| `paragraph_count` | int | 是 | 段落数量 |
| `table_count` | int | 是 | 表格数量 |
| `image_count` | int | 是 | 图片数量 |
| `language` | string | 是 | 文档语言（`zh`/`en`） |
| `generated_at` | string | 是 | 生成时间（ISO 8601） |
| `summary` | string | 是 | 文档摘要（200-300字） |
| `keywords` | array | 是 | 关键词列表 |
| `sections` | array | 是 | 章节结构 |
| `key_info` | object | 是 | 关键信息 |
| `tables` | array | 否 | 表格索引 |
| `images` | array | 否 | 图片索引 |
| `content_links` | object | 是 | 内容链接 |

### 需求文档扩展字段

当 `document_type` 为 `requirement` 时，必须包含以下字段：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| `requirement_type` | string | 是 | 需求类型：`schedule` / `excel` / `general` |
| `target_agent` | string | 是 | 目标 Agent：`excel-master` |
| `requirements` | object | 是 | 需求详情 |
| `requirements.task_description` | string | 是 | 任务描述 |
| `requirements.constraints` | array | 否 | 约束条件列表 |
| `requirements.inputs` | array | 否 | 所需输入列表 |
| `requirements.expected_output` | string | 否 | 期望输出描述 |

### keywords 字段结构

```json
{
  "keyword": "关键词文本",
  "frequency": 12,
  "relevance": 0.95
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `keyword` | string | 关键词 |
| `frequency` | int | 词频 |
| `relevance` | float | 相关度（0-1） |

### sections 字段结构

```json
{
  "heading": "章节标题",
  "level": 2,
  "paragraph_range": [1, 15],
  "key_points": ["要点1", "要点2"],
  "content_link": "{workspace}/summary/<文件名>/text/content.json#/paragraphs/0-14"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `heading` | string | 章节/主题名称 |
| `level` | int | 标题层级（1/2/3） |
| `paragraph_range` | array | 段落范围 [起始, 结束] |
| `key_points` | array | 要点列表 |
| `content_link` | string | 指向 content.json 的链接 |

### key_info 字段结构

```json
{
  "data": [{"value": "关键数据", "location": "paragraph_5"}],
  "conclusions": [{"text": "核心观点", "location": "paragraph_12"}],
  "references": [{"text": "重要引用", "location": "paragraph_20"}]
}
```

| 子字段 | 类型 | 说明 |
|--------|------|------|
| `data` | array | 关键数据/数字 |
| `conclusions` | array | 核心结论 |
| `references` | array | 重要引用 |

### tables 字段结构

```json
{
  "index": 0,
  "description": "表格内容简要描述",
  "rows": 5,
  "columns": 4,
  "location": "paragraph_8",
  "content_link": "{workspace}/summary/<文件名>/text/content.json#/tables/0"
}
```

### images 字段结构

```json
{
  "file": "image_1.png",
  "path": "{workspace}/summary/<文件名>/img/image_1.png",
  "description": "图片内容简要描述",
  "has_text": true,
  "ocr_link": "{workspace}/summary/<文件名>/img/text/image_1.txt",
  "summary_link": "{workspace}/summary/<文件名>/img/img-summary/image_1.md"
}
```

## 知识库扩展字段

knowledge-builder 在 summary.json 基础上扩展以下字段：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| `idea` | string | 否 | 文档中的研究想法或主题 |
| `concepts` | array | 否 | 文档的核心概念列表 |
| `relations` | array | 否 | 概念和关键词之间的关系 |
| `research_methods` | array | 否 | 文档中使用的研究方法 |

### concepts 字段结构

```json
{
  "concept": "概念名称",
  "definition": "概念定义",
  "frequency": 5,
  "related_keywords": ["关键词1", "关键词2"]
}
```

### relations 字段结构

```json
{
  "source": "概念/关键词A",
  "target": "概念/关键词B",
  "relation_type": "相关/因果/包含/...",
  "description": "关系描述"
}
```

### research_methods 字段结构

```json
{
  "method": "研究方法名称",
  "description": "方法描述",
  "location": "paragraph_15"
}
```

## phd-research-agent 输出结构

phd-research-agent 根据任务类型输出不同的结构化结果。

### 输出路径

```
WORKSPACE/{ProjectName}/phd-research-agent/summary/
├── manifest.json           # 处理清单
├── idea_result.json        # Idea 评估结果
├── idea_result.md          # Idea 评估报告（可读）
├── intro_outline.json      # Introduction 大纲
├── intro_outline.md        # Introduction 大纲（可读）
├── review_result.json      # 论文审阅结果
└── review_result.md        # 论文审阅报告（可读）
```

### Idea 评估结果 (idea_result.json)

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| `source_file` | string | 是 | 原始文件名 |
| `generated_at` | string | 是 | 生成时间（ISO 8601） |
| `verdict` | string | 是 | 评估结论 |
| `scores` | object | 是 | 五维评分 |
| `fatal_flaws` | array | 是 | 致命缺陷列表 |
| `suggestions` | array | 是 | 改进建议 |

**verdict 取值**：
- `Strong Accept`：无致命缺陷，总分 ≥ 20
- `Accept with Revisions`：无致命缺陷，总分 < 20
- `Reject and Pivot`：存在致命缺陷

**scores 五维评分结构**：

```json
{
  "higher": 1-5,  // 更高：提升性能/效果
  "faster": 1-5,  // 更快：提升效率/速度
  "stronger": 1-5, // 更强：增强鲁棒性/泛化
  "cheaper": 1-5,  // 更省：降低成本/资源
  "broader": 1-5   // 更广：扩展应用场景
}
```

### Introduction 大纲 (intro_outline.json)

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| `source_file` | string | 是 | 原始文件名 |
| `generated_at` | string | 是 | 生成时间（ISO 8601） |
| `paragraphs` | array | 是 | 六段式大纲 |
| `contributions` | array | 是 | 贡献列表 |

**paragraphs 六段式结构**：

| 索引 | purpose | 说明 |
|------|---------|------|
| 0 | 背景介绍 | 领域重要性、研究对象 |
| 1 | 现有工作 | 现有方法及其局限性 |
| 2 | 问题本质 | 核心问题、研究目标 |
| 3 | 关键挑战 | 技术难点、挑战列表 |
| 4 | 解决方案 | 方法概述、技术路线 |
| 5 | 贡献总结 | 明确列出贡献点 |

**paragraphs 字段结构**：

```json
{
  "purpose": "段落目的",
  "content": "要点内容"
}
```

### 论文审阅结果 (review_result.json)

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| `source_file` | string | 是 | 原始文件名 |
| `generated_at` | string | 是 | 生成时间（ISO 8601） |
| `issues` | array | 是 | 问题列表 |
| `summary` | object | 是 | 问题统计 |
| `verdict` | string | 是 | 审阅结论 |

**verdict 取值**：
- `Ready`：可以提交
- `Needs Revision`：需要修改
- `Not Ready`：不适合提交

**issues 字段结构**：

```json
{
  "severity": "CRITICAL | MAJOR | MINOR",
  "category": "logic | grammar | format | figure",
  "location": "问题位置",
  "description": "问题描述",
  "suggestion": "修改建议"
}
```

**severity 说明**：

| 级别 | 说明 |
|------|------|
| CRITICAL | 致命问题，必须修复 |
| MAJOR | 严重问题，强烈建议修复 |
| MINOR | 轻微问题，建议修复 |

**summary 字段结构**：

```json
{
  "critical": 0,
  "major": 0,
  "minor": 0
}
```
