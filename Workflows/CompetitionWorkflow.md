# 竞赛资源处理工作流 v2.0

**目标**：处理的竞赛资源包，通过 3 轮用户交互确定 PPT 方案，从文档中提取核心点生成精简型演示文稿，构建可成长式知识库。

---

## 核心原则

> **每页最多 3-5 条要点，每条不超过 15 个汉字。**
> 所有文字优先使用文档中的核心关键词和短句，禁止大段文字。

```
文字优先级：图表 > 关键词+短句 > 完整句子 > 禁止使用段落
```

## 用户交互详解

### 交互一 ⛔: PPT 类型选择

| 选项 | 场景 | 叙事策略 | 页数 |
|------|------|---------|------|
| **介绍型** | 项目展示、路演 | 视觉冲击、亮点突出、说服性 | 9-11 |
| **答辩型** | 竞赛答辩、专家评审 | 逻辑严谨、论证充分、学术性 | 10-11 |

### 交互二 ⛔: 视觉风格选择

| 选项 | 配色基调 | 适合场合 |
|------|---------|---------|
| **学术风** | 深蓝+白底，衬线标题，大量留白 | 高校答辩、论文评审 |
| **科技风** | 深色背景+青蓝/紫色渐变，几何线条 | 技术类、IT 类项目 |
| **简约风** | 浅色+单色强调，极简克制 | 注重信息传递的场景 |
| **商务风** | 金色+深灰，稳重专业 | 商业计划书、创业路演 |

### 交互三 ⛔: 竞赛赛道选择

| 选项 | 评审侧重点 | 影响 |
|------|-----------|------|
| **挑战杯（大挑）** | 社会价值、实践过程、创新意义 | 增加实践过程页、社会价值页 |
| **创青春（小挑）** | 商业逻辑、市场分析、竞争优势 | 增加竞品分析页、商业模式页 |
| **互联网+** | 技术创新、商业模式、带动就业 | 增加就业带动页、商业模式页 |
| **通用** | 创新性、可行性、完整性 | 平衡覆盖所有方面 |

## 核心点提取规则

PPT 文字来源于文档，但必须精简为短核心点：

| 提取类型 | 数据来源 | 输出要求 |
|----------|---------|---------|
| 背景提取 | 项目背景/概述 | ≤3 个数据 + ≤1 句痛点 |
| 技术提取 | 核心功能/技术路线 | ≤3 个关键词，每个 ≤1 句 |
| 创新点提取 | 创新点/项目优势 | 3-5 条，每条 ≤12 字 |
| 数据提取 | 实验结果/项目成果 | 原数值 + 短标签 |
| 团队提取 | mods.toml/README | 角色 + ≤8 字描述 |
| 对比提取 | 竞品对比/方案对比 | ≤5 行表格，每格 ≤10 字 |

| 路径 | 说明 |

## 错误处理

| 场景 | 策略 |
|------|------|
| 文档内容提取失败 | 终止工作流 |
| 用户未选择（超时） | 各选项使用默认值继续 |
| user_choices.json 字段缺失 | 默认值填充（defense+academic+generic） |
| 核心点提取后某页为空 | 跳过该页，不生成空白幻灯片 |
| knowledge-base/ 不存在 | 首次 init 模式构建 |
