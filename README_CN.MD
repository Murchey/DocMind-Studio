# DocMind-Studio

> AI 驱动的多类型文档总结与输出平台

[English](./README.MD)

---

## 项目概述

DocMind-Studio 是一个 AI 驱动的多文档分析、结构化知识库构建和自动化输出平台。类似 Google NotebookLM，但具备多文件知识库总结和索引能力，能将零散文档转化为结构化、可操作的输出成果。

**核心理念**：将多种文档源（DOC、DOCX、PDF、PPT、Excel、TXT、MD）转化为结构化知识库和专业输出（报告、演示文稿、格式化文档）。

---

## 核心特性

- **多文档处理**：同时处理 DOC、DOCX、PDF、PPTX、XLSX、TXT、MD 文件
- **结构化知识库**：构建可搜索、可链接的知识仓库，含 JSON 索引，支持增量更新与跨 Agent 注册
- **工作流引擎**：预置学术、企业、竞赛、知识库构建等场景的工作流
- **Agent 系统**：模块化 Agent 处理特定任务（文档分析、格式化、Excel 处理、PPT 生成、论文辅助）
- **AI 格式合规检查**：自动解析 DOCX XML 结构，检查并修复格式问题（字体、行距、页边距、三线表等）
- **进度可视化**：ProgressTracker 实时追踪任务进度，插件 Dashboard 同步显示
- **多格式输出**：生成 DOCX、PPTX、Excel、Markdown、HTML 等格式

## 工作流

### KnowledgeBuilder（知识库构建）
将多个文档转化为结构化知识库，含索引、关键词和交叉引用。支持增量更新与跨 Agent 注册。

**触发关键词**：知识库、结构化、批量处理、关键词提取、增量更新

### AcademicDocs（学术文档处理）
处理学术论文，包括内容提取、论文评审、Introduction 起草、开题报告生成、格式化输出。

**触发关键词**：论文、学术、评审、开题报告、文献综述、格式化

### EnterpriseDocs（企业文档处理）
分析企业文档，包括会议纪要、报告、数据表格对比和汇报 PPT 生成。

**触发关键词**：报告、企业、会议纪要、数据分析、汇报PPT

### Competition（竞赛资源处理）
处理竞赛资源包，自动提取项目核心点，生成精简答辩 PPT 和项目知识库。

**触发关键词**：竞赛、答辩、挑战杯、创青春、互联网+、项目书

## 应用场景

### 学术/课程场景
- 接收学长半途交付的项目资料
- 生成完整的答辩 PPT 和项目申报书
- 整合零散不完整的结课资料
- 应对频繁修改需求，支持增量更新
- **论文辅助**：idea 评估、论文审阅、Introduction 起草、开题报告生成
- **格式智能检查**：自动检测并修复字体、行距、页边距、三线表等格式问题

**为什么需要 DocMind？**
- 自动梳理零散资料 → 抽取核心信息 → 生成成果文档
- 需求变更时支持增量更新
- AI 格式检查确保论文符合学术规范，无需人工逐项核对
- 节省人工整理时间

**非它不可的时刻**：手上有 20+ 文档，明天要做出可展示的答辩成果。

### 企业/业务场景
- 整理多个项目表格、会议纪要和课程安排
- 对比和汇总多数据源
- 生成汇报表格、PPT 和计划文档

**为什么需要 DocMind？**
- Excel Master + Doc/PPT Master 自动生成对比和汇总
- Knowledge Builder 维护可成长的知识资产
- 避免重复人工操作

**非它不可的时刻**：手上有 10+ 表格和多份会议纪要，需要短时间内生成汇报成果。

## 为什么选 DocMind？

### vs 钉钉/飞书等企业工具
企业工具处理标准流程很好，但遇到"把 20 篇论文格式化成统一规范"这类个性化需求就不行了。DocMind 擅长的就是这类细粒度、定制化的文档处理。

### vs ChatGPT/千问等 AI 对话
AI 对话工具是一次性的——聊完就没了。DocMind 构建**可成长的知识库**，你的文档资产会持续积累，下次处理同类项目时可以直接复用。

### vs NotebookLM / AnythingLLM
NotebookLM 擅长个人知识管理，但输出是文本而非可用的文件。DocMind 直接输出**格式化的 DOCX 论文**和**可演示的 PPT**，拿来就能用。

## 技术亮点

### AI 格式合规检查（format-ai-checker）
- **原理**：将 DOCX 文件作为 ZIP 解压，直接读取内部 XML 结构（`word/document.xml`、`word/styles.xml`），精确解析每个格式属性
- **检查项**：页面尺寸/边距、字体字号、段落对齐/行距/缩进、标题层级格式、三线表规范、文档结构完整性
- **自动修复**：发现问题后自动修改 XML 属性并重新验证，最多循环 3 轮，确保格式合规
- **零外部依赖**：不依赖 PDF 转换或视觉模型，纯 XML 解析，速度快、精度高

### 知识库增量更新
- 通过 `content_hash` 指纹对比，只处理新增/变更/删除的文档
- 跨 Agent 注册机制，多个 Agent 的分析结果可汇入同一项目知识库

## 快速开始

### 第一步：告诉我你要做什么

在对话中描述你的需求，例如：

- "帮我把这些论文整理成开题报告" → 系统自动走**学术工作流**
- "这是我们的竞赛资源包，帮我出答辩 PPT" → 系统自动走**竞赛工作流**
- "规范一下这篇论文的格式" → 系统自动走**格式化 + AI 检查**
- "帮我对比这几个表格的数据" → 系统自动走**Excel 处理**
- "把这些文档建成知识库" → 系统自动走**知识库构建**

### 第二步：提供文档

将你的文档放到项目工作区的 `input/` 目录下。系统会根据你选择的工作流自动创建对应目录：

```
WORKSPACE/{你的项目名}/
└── doc-content-analysis/
    └── input/
        ├── 论文1.pdf
        ├── 报告.docx
        └── 数据.xlsx
```

> 你不需要手动创建目录——调度器会自动完成。

### 第三步：等待处理，查看进度

调度器会自动编排整个流程。处理过程中，你可以通过 **VS Code 插件的 Dashboard** 实时查看每一步的进度：

- 文档内容提取完成 → 自动进入下一步
- 格式化完成 → AI 格式检查自动触发，发现问题自动修复
- 所有步骤完成 → 系统通知你

### 第四步：获取成果

处理完成后，在对应目录下获取你的成果文件：

```
WORKSPACE/{你的项目名}/
├── doc-form-master/output/         # 格式化好的论文 (DOCX)
├── ppt-master/output/              # 生成的答辩 PPT (PPTX)
├── excel-master/output/            # 对比分析结果
├── doc-content-analysis/summary/   # 结构化分析报告
└── knowledge-base/                 # 项目知识库（可随时查询）
```

你：帮我对比这几份课程表的差异
